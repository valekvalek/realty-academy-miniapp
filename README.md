# Realty Academy — Telegram Mini App

Мобильная образовательная платформа для сотрудников и специалистов в сфере недвижимости. Пользователь выбирает тему, проходит короткий интерактивный квиз, получает мгновенную обратную связь и зарабатывает XP.

## Что реализовано

- главная с продолжением обучения, дневной целью и серией занятий;
- каталог тем: рынок, жилые комплексы, продажи, ипотека и юридические вопросы;
- интерактивный квиз из пяти вопросов с разбором ответов;
- экран результата, XP, уровни и сохранение прогресса в браузере;
- недельный рейтинг и профиль с достижениями;
- адаптация под мобильный экран и Telegram WebApp API.

## Запуск

```bash
npm install
npm run dev
```

Для production-сборки:

```bash
npm run build
npm start
```

Готовую HTTPS-ссылку нужно привязать к Telegram-боту через BotFather.
